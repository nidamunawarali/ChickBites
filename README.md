# ChickBites

ChickBites is a modern and responsive fast-food restaurant website created as a web development project.

## Features
- Responsive restaurant website
- Hero section with explore menu and video modal
- Our Story (About Us) section with restaurant ambience & feature badges
- Popular Picks menu section with interactive cards
- Special Combo Feast banner
- Why Choose Us section with quality badges
- Customer reviews slider
- Ready to Enjoy? table reservation CTA section with booking modal
- Interactive shopping tray (cart) with live total calculation
- Responsive design for mobile devices
- Bootstrap modals and offcanvas drawer
- Font Awesome icons

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
- Google Fonts

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
